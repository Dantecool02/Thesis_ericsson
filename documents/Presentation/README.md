# Thesis defense presentation

Defense of "Adaptive Hybrid Retrieval-Augmented Generation" (DA233X, KTH, with Ericsson), 22 October 2026 on Zoom.

## What to open

- `presentation.html`: open in any browser to step through the slides with the speaker notes (arrow keys or click). Keep the `slides/` folder next to it.
- `Dante_Wesslund_Thesis_Presentation_v2_clean.pptx`: the deck to present, on KTH's official template. 20 main slides, backups on slides 21 to 25, the spoken script in the presenter notes. Open it in Keynote or PowerPoint with the Figtree font installed (`fonts/`).
- `Dante_Wesslund_Thesis_Presentation_v2_clean.pdf`: the same deck as a PDF, the fallback during the talk.
- `Speaker_script_v2_clean.md`: the full script with a time stamp and word count per slide.
- `Defense_prep.md`: run sheet, Zoom and Keynote checklist, and prepared answers to likely questions.
- `Things_to_learn.md`: the metrics, confidence intervals and statistical tests explained with your own numbers, with questions to check yourself. Start here.
- `Study_notes_results.md`: the results and the statistics explained.
- `Opposition_answers.md`: the opponent's ten questions in his order, each with the points of a two-minute answer.

Older material: `Dante_Wesslund_Thesis_Presentation.pptx` / `.pdf` and `Speaker_script.md` are an earlier, more detailed version of the talk. `reference/` holds the KTH template overviews.

## Rebuilding

Every number on the slides comes from `build/deck_data.json`. That file is generated by `build/deck_data.py` from the analysis outputs under `data/`, which are not in the repository, so on a fresh clone use the committed `deck_data.json` as it is.

```bash
cd documents/Presentation/build
python build_clean.py
```

That writes the `.pptx` and `Speaker_script_v2_clean.md`. To refresh the PDF and `presentation.html` (macOS with Keynote; needs python-pptx, lxml and pymupdf):

```bash
./render_keynote.sh "$PWD/../Dante_Wesslund_Thesis_Presentation_v2_clean.pptx" /tmp/deck_render
cp /tmp/deck_render/deck.pdf ../Dante_Wesslund_Thesis_Presentation_v2_clean.pdf
python make_viewer.py ../Dante_Wesslund_Thesis_Presentation_v2_clean.pdf ../Dante_Wesslund_Thesis_Presentation_v2_clean.pptx .. viewer_template.html
```

Keynote only sees fonts that were installed before it started, so restart Keynote after installing Figtree.
